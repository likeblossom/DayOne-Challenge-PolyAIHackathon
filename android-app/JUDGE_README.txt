SANAD — INSTALLATION AND USE

IMPORTANT: THE APK ALONE DOES NOT INCLUDE THE OCR MODELS.

CONTENTS
  Sanad-v0.2.0.apk       Android app
  Sanad-models-v1.zip    OCR/detection model pack (about 2.94 GB)
  README.txt            These instructions

1. EXTRACT THE OUTER ZIP
   Extract Sanad-v0.2.0-judge-kit.zip.
   DO NOT extract the inner Sanad-models-v1.zip.

2. INSTALL THE APP
   Use a 64-bit Android phone running Android 8 or newer.
   Open Sanad-v0.2.0.apk on the phone. If Android asks, allow your
   browser/file manager to install apps, then install Sanad.

3. IMPORT THE MODELS ONCE
   Put Sanad-models-v1.zip in the phone's Downloads folder.
   Open Sanad > Settings (top right) > Import model pack.
   Select Sanad-models-v1.zip, NOT Sanad-v0.2.0-judge-kit.zip.
   Keep Sanad open until the message "Models ready" appears.
   No computer, account, Wi-Fi or USB connection is needed for OCR afterward.

4. READ A FORM
   Choose a registry when prompted.
   Tap the paperclip to select a form image, or the camera to take a photo.
   Wait for extraction, review/edit the fields, then submit.
   Tap the attached image to zoom. Saved records remain accessible offline.
   This app supports the eight maternal/newborn form layouts in the project;
   it is not a general-purpose document scanner or medical diagnosis tool.

FREE SPACE
   Allow 10 GB free if downloading/extracting the whole kit on the phone.
   Or extract on a computer, copy only the APK and model ZIP to the phone,
   and allow 6 GB free on the phone before import.
   After successful import, downloaded ZIPs can be deleted.
   Do not clear Sanad's app storage: that deletes installed models and records.

TROUBLESHOOTING
   Import fails: check free space and select the INNER Sanad-models-v1.zip.
   Incomplete download: download again before retrying.
   Existing development build/signing conflict: use another phone.
   Do not uninstall an app containing records you need to keep.
   PC database sync is optional and needs the separate USB receiver setup.
